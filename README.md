# Oberth Homebrew Tap

Homebrew tap for [Oberth](https://github.com/oberthci/oberth) — a single-node
Git-over-SSH CI service for Kubernetes with repository-owned Go pipelines.

## Install

```sh
brew install oberthci/tap/oberth
```

or

```sh
brew tap oberthci/tap
brew install oberth
```

## What this repository is

A pure distribution point. `Formula/oberth.rb` is generated by the release
process in [`oberthci/oberth`](https://github.com/oberthci/oberth) — the
monorepo's `homebrew/Formula/oberth.rb` is the source of truth, and a
byte-identical copy is pushed here on every release. Do not edit the formula
by hand; a hand edit desynchronizes the version/URL/digest lockstep the
release pipeline guarantees.

The formula downloads the platform binary from the canonical release origin
`https://releases.cloudtaser.io/oberth/<tag>/` and Homebrew verifies its
SHA256 against the digest pinned for that exact version. All four platforms
(macOS/Linux x amd64/arm64) are pinned from the release's cosign-signed
`SHA256SUMS`.

## Verifying

```sh
sh hack/verify-formula.sh
```

Phase 1 checks the formula structure offline (version field, four platform
URLs, four 64-hex digests, HTTPS only). Phase 2 downloads every platform
binary and re-derives its SHA256 independently of the release build. The same
check runs as this repository's `.oberth/periapsis.go` pipeline on every push.
